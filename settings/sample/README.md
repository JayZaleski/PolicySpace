# Sample setting

The project's sample setting, used to try out the engine. It is a folder of TOML files: `setting.toml` is the manifest, `rules/` holds the persistent rules (constants that never change during play), and `start/` holds the starting state (what turn 0 looks like). Put notes in a `README.md` like this one: any other file that isn't a `.toml` file is an error.
